# dsh-sort-out-the-thoughts · 梳理思路

把一句模糊的念头，聊成一个真能写出来、真能讲出来的东西。

对话框输入框左边有一个「💭 梳理」开关。打开它，AI 换一副面孔：不急着替你写，先问你——这东西到底想说什么、凭什么成立、谁会不同意、缺哪块材料。它质疑你，也帮你自己质疑自己。

打开之后不是随便聊，而是走三段：**先梳理**（把你自己的观点，和我们聊出来的观点分开列清）、**再批判**（一针见血指出方案和认知里的致命缺陷）、**最后调研**（把你的问题抽象成可检索的命题，跨领域查证，再落回你的需求）。每一段的结论都会单独存在这条思路里，换段不会覆盖上一段。想法往前推进的时候，它顺手把主旨、结构和还没解决的问题记下来；关掉开关，这一条就归档进 **设置 → Thoughts Center**，按体裁分组，可以搜，可以回看三段各自留下了什么、也可以接着往下追问。

给写文章、写演讲稿、写自媒体文稿的人用。

想法常常还没成形，不配叫「一条思路」。所以右下角常驻一颗「📒 随想」小球：想到什么先记一句，攒着；哪天想认真梳了，点开本子挑一条点「去研究」，它就直接从这个念头开始问，不用你重述一遍。

## 它解决什么问题

写不出来，多数时候不是文笔问题，是想法还没长完。脑子里那团东西，自己跟自己绕，绕到最后要么放弃，要么硬写出一篇自己都不信的东西。

这个插件把「想清楚」这件事变成一段有节奏的对话，并且留痕：

- **开关即模式**：只对当前这个对话生效，不污染别的会话。
- **随想记录本**：一颗悬浮球，点一下就在原地变成一本带横线的草稿本（球隐去，位置不跳）；点本子右上角 ×，又变回球。球和本子都能按住拖动，位置记在一处。四色纸面可选（纸米黄 / 护眼绿 / 白纸 / 深灰）。碎想法先存着，不用当场起标题、定体裁；每条下面一个「去研究」：点它会新开一条会话，并把这句随想连同一句「先把这条想法梳理清楚」按固定模板直接写进那条会话的输入框，梳理开关也自动打开——想限定研究方向，就在输入框最后补一句再回车。设置里的 Thoughts Center 也有「随想」页签，能看全部记录。
- **三段推进**：梳理 → 批判 → 调研，按顺序走，不跳段。每段的结论分开存，看得见想法是怎么被一层层逼出来的。
- **换段先问一次路**：每一段快收尾时，它会停下来让你二选一——留在本段继续挖，还是进下一段。**同一段只提醒一次**；你也可以随时自己说「进下一段」，不用等它问。
- **一键推进**：聊够了不用等它问。输入框旁边会多出一个「推进到第2段」按钮，你觉得这一段的活干完了就点它；到第三段再点就是「定稿归档」。它不会拦着你，只是先帮你过一遍这一段该留下的东西（主旨、成形的内容、本段结论），缺了就告诉你缺哪几项，再点一次仍然可以硬推。
- **换段有产物清单**：每一段都有自己该留下的东西，像工地交接一样逐项打勾。清单是机器判的「有 / 没有」，判得好不好仍然是你的事。
- **提问优先**：每轮最多两三个具体问题，问到要害，问完停下等回答，不一次抛十个。
- **边聊边存**：不用手动保存，推进了就落一次状态。
- **可回看**：Thoughts Center 里能看到每条思路的三段结论和演化轨迹——哪一步从「刚起念」到「有骨架」。
- **可带走**：一条思路一键导出 Markdown，丢进任何写作工具继续。

## 安装

在 DSH 会话里让智能体装（官方推荐路径）：

```
plugin_manager action=install_bundle target=<这个目录的绝对路径>
```

装完这一步不要重启，先确认 `application: applied`。然后在对话框左边就能看到「💭 梳理」开关，右下角能看到「📒 随想」球。

## 使用

1. 打开一个对话，点输入框左边的「💭 梳理」。
2. 把脑子里那团东西随便说出来，越糙越好，不用组织语言。
3. 回答它的追问。它问得烦，你就说「别问了，先给我个骨架」——它会照办。
4. 想收尾时说一句「差不多了，定稿」，这条就归档。
5. 去 **设置 → Thoughts Center** 找它。

## 随想记录本

想法还碎的时候，别逼自己先给它起个标题。

1. 点右下角那颗「📒」球——球当场变成本子，位置不跳。再点本子右上角「×」，本子变回球，**球回到它原来待的地方**（球和本子各记各的位置，不会互相带着跑）。只有你把本子拖到别处后再关，球才会跟到本子的右下角——因为那时「挂件」就在那儿。拖到屏幕边上会自己弹回来，不会掉出去。
2. 本子右上角四个小圆点是纸色：纸米黄、护眼绿、白纸、深灰。点一下就换，记住你选的那一种。
3. 想到什么写一句，「记下」（`⌘/Ctrl + Enter` 也行）。字压在横线上，跟真本子一样。不用管体裁、不用管顺序，它就是一堆句子。
4. 下面那行「随想记录 · N 条」默认是收着的，点开本子才变长、列表自己滚动，不会一上来就占半屏。
5. 攒到某天想认真梳了，挑一条点「去研究」：它新开一条会话，把那句话按固定模板写进输入框，梳理开关也顺手替你打开——不用自己再点一次。想限定方向就在末尾补一句，然后回车。
6. 用过的随想会标「已开过」，但不会消失——之后还能拿它再梳一条。
7. 不想在对话框里翻：**设置 → Thoughts Center → 随想** 页签里也有全部随想，能看时间、能删。
8. 「推进到第 N 段」这个按钮只在这一段真落下东西之后才出现。刚点进来、一句还没聊的时候它不占地方，免得你以为已经聊了一半。

记录本里的随想和思路库分开存：随想是原料，思路是成品，成品归档进 Thoughts Center，原料继续留在记录本。

## 数据在哪

```
<DSH_HOME>/plugin-data/dsh-sort-out-the-thoughts/
  thoughts.json   思路库（条目 + 演化轨迹）
  mode.json       哪些会话开着梳理模式
  sparks.json     随想记录本（原料）
```

`DSH_HOME` 默认是 `~/.dsh`。三个文件都是普通 JSON，随时可以备份或手工搬走。

## 配置

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `maxThoughts` | `500` | 条目上限。写满后会先淘汰最老的已归档条目。 |

## 它对外面暴露了什么

- 系统提示词片段 `sort-out-the-thoughts:mode`：**只在开关打开的那个会话里**注入，其余会话读到的是空串。
- 工具 `sort_out_thoughts`：`save` / `finish` / `list` / `get`。
- 本机路由 `/plugins/dsh-sort-out-the-thoughts/*`：只接受回环来源（127.0.0.1 / ::1 + localhost Host 头），来自别的网段的请求一律 403。含思路的读写，以及随记录的 `/sparks`、`/spark/add`、`/spark/update`、`/spark/delete`、`/spark/start`。

## 卸载

```
plugin_manager action=remove_bundle target=dsh-sort-out-the-thoughts
```

卸载不会删思路库。想彻底清掉，删掉上面那个数据目录即可。

## 边界

- 开关是**会话级**的，不跨会话继承。这是故意的：梳理模式会改变 AI 的说话方式，不该默默接管所有对话。
- 它负责把想法推成结构，不负责替你查证。事实、引语、数据仍然要自己核。
- 演化轨迹只记录「阶段 / 主旨 / 标题」的快照，不保存每一个版本的全文，避免库无限膨胀。要保全文就导出。

## 它借鉴了什么

三段的「产物清单 + 换段前机检 + 硬推留痕」这套做法，参照了 [lunheng-article-pipeline](https://www.npmjs.com/package/lunheng-article-pipeline) 的闸门思路：交付前先跑机械检查，失败项交给人裁定，人仍然可以选择推进，但推进这件事本身会被记下来。区别是论衡面向动辄数小时、要证据可追溯的长文，这里只取「每段有产物、换段有闸门、决定有留痕」三件事，其余一律砍掉——开了开关就能用，不需要先理解一套流程。
